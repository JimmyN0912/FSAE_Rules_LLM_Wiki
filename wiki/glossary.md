# Formula SAE (IC) 新手必備術語與縮寫對照表

剛接觸 FSAE 官方 PDF 時，滿頁的英文縮寫最容易卡關。以下收錄 IC 內燃機組最常出現的關鍵術語與白話對照：

| 縮寫 / 術語 | 英文全名 | 白話解釋 | 對應頁面 |
| :--- | :--- | :--- | :--- |
| **AIP** | Anti-Intrusion Plate | 防侵入板：擋在吸能緩衝器與前隔板之間的硬板（如 ≥ 4.0 mm 鋁板） | [[chassis-and-passive-safety]] |
| **BOM** | Bill of Materials | 物料清單：詳列整車或 2027 成本情境題中所有零件與製程費用的清單 | [[2027-static-sdf-scenario]] |
| **BOTS** | Brake Over-Travel Switch | 煞車超行程開關：煞車失壓踩到底時自動斷開斷電迴路熄火的保命開關 | [[driver-ergonomics-and-controls]] |
| **DNF / DOO / OC** | Did Not Finish / Cone Down or Out / Off Course | 動態賽常見判罰：未完賽 / 撞倒或撞出框錐筒（加秒） / 衝出賽道或漏門（直接 DNF） | [[competition-scoring-1000pts]] |
| **Egress** | Driver Egress Test | 緊急脫逃測試：全副武裝車手於車檢中快速熄火解扣逃出座艙（日本站由裁判當場指定方向） | [[technical-inspection-gauntlet]] |
| **FSAEJ** | Formula SAE Japan | 日本學生方程式分站，除全球規則外須同時遵守年度 Local Rules | [[fsaej-local-rules-diff]] |
| **IA / IAD** | Impact Attenuator / Data | 車頭吸能緩衝器（潰縮盒）及其壓潰測試數據報告 | [[chassis-and-passive-safety]] |
| **Percy** | 95th Percentile Male Template | 規則書 `F.5.6.5` 定義的第 95 百分位男性二維模板（200/200/300 mm 三圓） | [[chassis-and-passive-safety]] |
| **PS** | Pre-Competition Submissions | 2027 規則書賽前繳件章節（如 SES、IAD、Cost Report、Design Briefing） | [[rulebook-structure]] |
| **Restrictor** | Air Intake Restrictor | 進氣限流閥：所有進氣必經的單一圓孔（汽油 20.0 mm / E85 19.0 mm） | [[ic-powertrain-rules]] |
| **RFP** | Request for Proposal | 2027 商業簡報 Round 1 書面提案（上限 8 頁，20 分尺規） | [[2027-static-sdf-scenario]] |
| **SDF** | Software-Defined Feature | 2027 簡報與成本共用的「軟體定義車輛功能」主題 | [[2027-static-sdf-scenario]] |
| **SES** | Structural Equivalency Spreadsheet | 結構等效試算表：採碳纖單體殼或非基準鋼管時必交的強度等效證明 | [[chassis-and-passive-safety]] |
| **SIS** | Side Impact Structure | 側面防撞結構：保護座艙左右兩側，下緣距地須 ≤ 90 mm（`V.1.4.2`） | [[chassis-and-passive-safety]] |
| **Tech Sticker** | Inspection Sticker | 車檢貼紙：集滿四關車檢簽核貼紙，才是進入動態賽道的入場券 | [[technical-inspection-gauntlet]] |
